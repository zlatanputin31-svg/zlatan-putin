# ExamPilot AI: Startup Roadmap

## Phase 1: Core Solver (Week 1-2) - DONE
- [x] Multi-subject AI Solver integration.
- [x] OCR (Image-to-text) extraction.
- [x] Firebase History persistence.
- [x] Adaptive Explanation Engine (Beginner/Inter/Advanced).

## Phase 2: Engagement (Week 3-4)
- [ ] **Similar Question Generator**: AI generates 3 mock JAMB questions based on the last solve.
- [ ] **Voice Explanations**: Text-to-speech for the "Beginner" explanation mode.
- [ ] **Social Sharing**: "Share Solution" cards for WhatsApp study groups.

## Phase 3: Monetization (Week 5-6)
- [ ] **Subscription Gate**: Integration with Paystack/Flutterwave for "Unlimited Solves".
- [ ] **Exam Countdown**: Personalized study timer for WAEC/JAMB dates.
- [ ] **Offline Cache**: Save solutions for offline viewing.

## Monetization Model
1. **Free Tier**: 5 Solves/Day + Standard Explanations.
2. **Pro Tier (N1,500/mo)**: Unlimited Solves + AI Analogy Mode + Weakness Analytics.
3. **Institutional**: Bulk licenses for Secondary Schools.
